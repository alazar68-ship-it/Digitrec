# Security policy

## Supported versions

- 0.1.x

## Reporting a vulnerability

If you believe you found a vulnerability:

1. Do not open a public issue.
2. Share a minimal reproduction and impact assessment.
3. Provide environment details (OS, Python version, dependency versions).

## Baseline security expectations

- No hardcoded secrets.
- Input validation on all API endpoints.
- CSRF enabled for HTML/HTMX forms.
